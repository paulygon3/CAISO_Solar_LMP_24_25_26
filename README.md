# CAISO hourly zonal solar-weighted LMP

This project calculates solar-weighted day-ahead locational marginal prices from CAISO OASIS using three fixed, two-location PVWatts V8 profiles. The requested delivery periods are the full Pacific calendar years 2024 and 2025 and January 1 through November 18, 2026.

[Original specification](docs/task.txt) · [Download the verified resume archive](../../releases/tag/checkpoint-v1) · [Reference-hub results](results/verified_hub_periods.csv)

The checkpoint includes six all-location pilot days and the complete three-hub history. The full-market run is in progress. Final workbooks will appear in Releases after readback validation.

The checkpoint commands and assumptions are documented in [the run guide](docs/checkpoint.txt) and [the data cleaning notes](DATA_CLEANING_AND_LESSONS.md).
